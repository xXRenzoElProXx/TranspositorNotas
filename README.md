# Transpositor de Notas

> Transpone acordes de canciones por semitonos, alterna entre notación inglesa y latina y escucha una referencia sonora de cada acorde.

[![React](https://img.shields.io/badge/React-19-61DAFB?logo=react&logoColor=white)](https://react.dev/) [![TypeScript](https://img.shields.io/badge/TypeScript-6-3178C6?logo=typescript&logoColor=white)](https://www.typescriptlang.org/) [![Vite](https://img.shields.io/badge/Vite-8-646CFF?logo=vite&logoColor=white)](https://vite.dev/)

## Características
- Transposición por semitonos y accesos rápidos de medio tono y tono completo.
- Detección y transformación de acordes con Tonal.js.
- Cambio instantáneo entre notación inglesa (`C D E`) y latina (`Do Re Mi`).
- Previsualización sonora de acordes con Howler.js.
- Copia del resultado, reinicio de tonalidad y limpieza del texto.
- Diseño responsive inspirado en la interfaz de `rng-project`.

## Tecnologías
React, TypeScript, Vite, Tailwind CSS, Tonal.js, Howler.js y Oxlint.

## Inicio rápido
```bash
npm install
npm run dev
```
